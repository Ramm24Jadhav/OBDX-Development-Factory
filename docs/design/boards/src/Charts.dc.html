DESIGN SYSTEM · THREE NEW PARTS

Chart parts the Modernization screens need

The factory's design system has only the ring chart today. These three would be added to docs/DESIGN-SYSTEM.md and the Design System page, built from the same tokens, and used only where a table alone would hide the point.

Stacked bars fx-bar-chart

Used by: History (runs per week). Counts by state over time.
  • Colours from the status tokens: done --fx-primary, warning --fx-warning, failed --fx-danger; a legend with words, never colour alone.
  • Axis from 0 with whole-number ticks; bars 20–32 px; 2 px gap between segments.
  • role="img" with a summary, and a "Show as a table" link for the values.
  • Focus moves bar by bar with the arrow keys; the tooltip shows the week and each count.

Timeline fx-timeline

Used by: Migration planner. The team's planned weeks per module, and what is done.
{{r.n}}
  • Bar colour by state: delivered --fx-success, in progress --fx-info, planned --fx-primary, not started --fx-border-strong; state also written in the row.
  • A "Today" line; weeks or months; dragging a bar is not offered (weeks are edited in the row's ⋯ menu).
  • Each row is a list item that reads "Payments, planned weeks 4 to 5, not started".

Dependency diagram fx-dep-graph

Used by: Migration planner (small and full screen). Which module needs which.
{{i.n}}
  • Laid out in columns by what each module needs, so lines only go left to right; solid line "needs", dashed "needed by".
  • Nodes are buttons: picking one highlights it in the table and the order.
  • The same data as a table on the Dependencies tab, for screen readers and printing.
