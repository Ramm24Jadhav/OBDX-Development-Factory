## For the shared files (the main session applies these)

- **Running**: the web parity specs run with the existing gates (`cd target-packs/components/gates && npm run gates`;
  the config already serves 5181, 5182 and 5183). The React Native harness runs on its own:
  `cd target-packs/components/react-native/gates && npm install && npm run gates:update` the first time (it writes
  `react-native/gates/snapshots/<platform>/react-native-<id>-<theme>.png`), then `npm run gates`.
- **CI**: a job for the React Native harness (Linux is the screenshot reference):

  ```yaml
  react-native-gates:
    runs-on: ubuntu-latest
    defaults: {run: {working-directory: target-packs/components/react-native/gates}}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: {node-version: 22}
      - run: npm ci --prefix .. && npm install
      - run: npx playwright install --with-deps chromium
      - run: npm run gates
  ```

- **packs.json**: React Native's gates can list `screenshots`, `themes` and `contrast` once the job is green; React
  and Angular gain `parity`.
- **docs/COMPONENT-PACKS.md**: the gates table can name the two parity specs and the React Native harness.
