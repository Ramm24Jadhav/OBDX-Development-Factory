## For the shared files (the main session applies these)

- **bx.css**: done in this commit (the section `/* ---------- Group 7: text effects, motion, showcase, backdrops, micro interactions ---------- */`, in all four copies).
- **Exports**: done in this commit (`bx.js` adds bx-g7's elements; `react/src/index.ts` and `angular/src/index.ts` export the 69 components and `stagger`; `OBDX_COMPONENTS` includes `G7_COMPONENTS`).
- **motion.json**: done in this commit (one entry per component).
- **Written clean-room**: only the plan's list of names and ideas was used; no effects library's source was opened, copied, ported or translated. No new dependency: CSS, the Web Animations API, timers and a plain canvas.
- **PackFiles.java**: ship `jet-premium/bx/bx-g7.js` (bx.js loads it; it loads bx-g1, g2, g3, g5 and bx-motion).
- **catalogue.json**: five new categories, ids `text-effects` (Text effects), `motion` (Motion), `showcase` (Showcase components), `backdrops` (Backdrops) and `micro-interactions` (Micro interactions); each entry below names its category. Add `react-native` names when the phone session builds them (N3).
- **Not for banking** (the plan lists these in the catalogue so the choice is visible; none is built): cursor trails, blobs and crosshairs, glitch, ASCII and distorted text, 3D galleries and models, physics toys, and the loud backdrops (galaxy, hyperspeed, lightning, ball pit).
- **Renamed in this commit, for safety**: the balance card's `hidden` is now `amountHidden` (in JET an attribute named hidden hid the whole element), and `handoff/W2.md` is regenerated with it. The swipe row and profile card take `heading` and `jobTitle`, not `title` and `role`, for the same reason (they land on the host element).
- **Accessibility**: every text effect keeps the whole text once for screen readers and hides the moving copy; the carousel never moves by itself; the marquee has Pause and stops on hover and focus; slide-to-confirm confirms on a press too (no dragging needed); hold-to-confirm works with Space and Enter; swipe-row actions are reachable by keyboard; backdrops are decoration (aria-hidden).
- **motion.json** has the 69 (245 components in all).
