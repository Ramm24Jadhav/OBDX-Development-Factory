## Built

| Component | JET element | React | Angular | React Native | Unit tests |
|---|---|---|---|---|---|
| The 23 built components (foundation and forms wave) | motion in bx.css; bx-number-input rolls its number on a step | same CSS; NumberInput rolls | same CSS; bx-number-input rolls | not built (`react-native: false`, the phone session sets it) | JET 34, React 41, Angular 34 |

- `target-packs/components/motion.json`: one spec per component (enter, hover, press, change, open, error, loading, packs) and
  the vocabulary of effects. `style` means the component style's hover, click or scroll class.
- `bx.css` (all four copies, byte-identical): the tokens `--bx-dur-fast|base|slow`, `--bx-ease-standard|exit|spring`; a
  `Motion layer (M1)` section: hover and press on choices, tabs, steppers, switches and interactive cards for each style
  class; scroll entry for grids, drop zones and fields; change (choice mark and chip pop, switch knob spring, chosen tab
  settles, new rows and files settle); open (dialog spring, list drop, toast slide); error (a field shakes once when its
  message appears); loading (a busy button shimmers). Every keyframe animates from a start state to the element's own
  style, so with no motion the end state shows. The reduced-motion rule now covers every `bx-` class and pseudo-element.
- Script for a value change: `jet-premium/bx/bx-motion.js` (AMD, no dependency), `react/src/motion.ts` and
  `angular/src/motion.ts` (the same file): `play(element, effect)` with the Web Animations API, `reducedMotion()`,
  `EFFECTS` (roll, pop, shake, settle, pulse). Nothing plays under reduced motion or without the API (old browsers on JET 6).
