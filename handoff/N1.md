### Props by kind (for the catalogue's `api` blocks)

Fields (Slider, ToggleGroup, FilterChips, AccountSelector, AccountNumber, BeneficiarySelector, PaymentSchedule,
MaturityInstructions, the code inputs, ConvertToEmi, RedeemPoints, CardLimits, CardControls, BlockCard, PromiseToPay):
the shared field props (`testID`, `label`, `value`, `onChange`, `required`, `readOnly`, `disabled`, `helpText`, `error`)
plus:

- `options` (ToggleGroup, FilterChips, TransactionFilter, PaymentSchedule, MaturityInstructions, CardControls), `single` (chips).
- Slider, RedeemPoints: `min`, `max`, `step`, `currency`; RedeemPoints `pointValue`.
- AccountSelector: `accounts: Account[]` (`id`, `name`, `number`, `balance`, `available`, `currency`), `showBalance`; value is the account id.
- AccountNumber: `format: 'iban' | 'account'`. BeneficiarySelector: `payees: Payee[]`, `onAdd`.
- ActivateCard, OtpInput: `length`, `onComplete`; OtpInput `resendAfter`, `onResend`. ResetPin: `length`, `onComplete` (both entries match).
- ConvertToEmi: `amount`, `annualRate`, `plans`, `currency`. CardLimits: `max`, `used`, `currency`. BlockCard: `confirm`.
- PromiseToPay: `rows`, `min`, `max`, `onSubmit(date)`, `busy`.

Forms (PaymentForm, NewDepositForm, LoanRepayment, RaiseDispute, AddOnCard): `value` is an object written back whole,
`label` optional, checked when the review button is pressed; `onReview(value)` / `onSubmit(value)` only when valid.

Display: Key-value cards (AccountDetails, TransferSummary, TransactionDetails, DepositTopUp, DepositRedemption):
`rows: {label, value, emphasis?}[]`, `actionLabel`, `onAction`, `busy`. Tiles (AccountSummary, DepositsSummary,
LoansSummary, CardList): `tiles: {id, title, value, note, tone}[]`, `value`, `onChange`. Steps (Stepper, PaymentStatus,
KycSteps): `steps`, `value` (index). Timelines (Timeline, DisbursementTimeline): `events: {title, detail, state}[]`.
Banners (Alert, ErrorMessage, SuccessMessage, FraudAlert): `label`, `detail`, `tone`, `actionLabel`, `onAction`,
`onClose`; FraudAlert `onAllow`, `onBlock`. Lists (NotificationPanel, UpcomingBills, CardStatements): items and one
action per row. Others as in the source's doc comments.
