Policies

  • API keys are stored on the factory server, encrypted, and never sent back to the browser.
  • The bank's code goes only to the model server chosen here. Choose a server on this computer or the bank's network for sensitive code.
  • Generated code is checked against the version pack rules and never written to trunk: it is delivered as a patch or an SVN branch.
  • Every model setting change is recorded in the audit log (Administration).
