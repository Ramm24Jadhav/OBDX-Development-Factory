Recipes and templates are kept in version pack files so they are reviewed like code. To add or change one, put a recipes.yml (and templates) in the team pack folder named by FACTORY_PACKS_DIR, using the same keys as the factory's own packs (id, title, when, match, guidance, parts), then restart the factory. A recipe with the same id replaces the factory's.
