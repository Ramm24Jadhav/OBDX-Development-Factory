When a bank reports an error, describe it and add the logs and screenshots. The factory finds the evidence, looks it up in the bank's code and configuration and in the Oracle notes and manuals of the Library, and suggests the cause and how to fix it. If it looks like a product defect, draft an Oracle Service Request.
