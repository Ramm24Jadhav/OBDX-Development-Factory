Technology settings

What the factory uses when it moves a module to each technology. Administrators can change them for this workspace.
The target pack is still being built. These settings are a preview and can't be used for a migration yet.

The Look rows come from the component style saved in the Component factory; change them there. Locked settings are the OBDX rules: changing them would break the bank's session, security or services, so they are fixed for every technology.

Changes apply to new migrations in this workspace. Running ones keep their settings.
