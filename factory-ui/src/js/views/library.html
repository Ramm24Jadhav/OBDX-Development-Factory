Oracle's manuals from Oracle's site

The factory gets the OBDX manuals from docs.oracle.com and keeps them current: every week it asks Oracle which manuals changed (a new patchset or a fix) and downloads only those, one at a time. Each file must be a genuine PDF from Oracle's site with no scripts or embedded files before it is read. Nothing of the bank's is sent to Oracle.
