Run on the factory server on every generated file, and again before each Jenkins build: syntax at the bank's Java level, plus the rules of the OBDX version pack. Errors go back to the model to fix; warnings are shown to reviewers. Only lines added by a change are checked. Turn a rule off when this bank's codebase deliberately does it differently.
